# 本地密码库

MemoDesk 0.10.3-preview 提供独立密码库。它离线工作，不需要云账号，默认使用 `Ctrl+Alt+P` 快捷检索。所有密码操作独立于原有备忘、工作记录、提醒和 AI。

## 开始使用

1. 点击顶部“密码库”，设置 10–1024 字符的主密码。支持空格和中文，不会自动去掉首尾空格，也不要求同时包含字母、数字或符号。输入不符合要求时，会在输入框附近说明具体原因；格式失败保留输入供修改。
2. 点击“新建账号”，填写名称、用户名、密码、网址、分类、标签和保密备注。可以直接输入新分类名称。
3. 选择账号后复制用户名或密码；“显示 10 秒”需要主动点击，切换条目和失去焦点时立即隐藏。
4. 通过“导出加密备份”将 `.memovault` 保存到其他位置。忘记主密码后无法通过备份重置密码。

快捷窗口里，Enter 复制当前结果的密码，Ctrl+Enter 复制用户名。首次建库仍从主界面完成；已有库在快捷窗口内解锁后即可搜索。

密码库提供收藏、分类、回收站和彻底删除。旧备份或系统快照可能仍保留已删除内容，软件不承诺擦除这些历史副本。

## 锁定和剪贴板

默认无密码库操作 5 分钟锁定，可选 1 / 5 / 15 分钟。隐藏到托盘、最小化、系统锁屏、会话断开以及挂起/恢复事件均触发锁定；后台提醒不延长会话。

锁定清除页面元信息、检索词、编辑窗口和生成器，并撤销尚未完成的解锁结果。未保存的编辑在锁定时丢弃。

复制的内容默认 20 秒后清除。实现设置 Windows 禁止历史和云同步格式，清理时在剪贴板锁内核对序号；用户复制了其他内容后不再清除它。第三方剪贴板监控工具可能不遵守这些系统标记。

密码生成器中的“复制密码”按钮复制整个结果；选中文字后按 Ctrl+C 或右键复制时复制选中部分。这些入口均使用安全剪贴板，锁定后禁止复制。

## 存储与主密码

数据保存在 `%LOCALAPPDATA%\MemoDesk\vault\vault.db`，与 `memo.db` 分开。

- 每库生成随机 256 位数据密钥。
- 主密码通过 PBKDF2-HMAC-SHA256、32 字节随机 salt、600,000 次迭代派生包裹密钥；认证加密后的数据密钥与参数一起保存。
- 元信息和秘密分别使用 AES-256-GCM 加密，每次使用新的 12 字节 nonce 和 16 字节 tag。认证上下文绑定库、条目、版本和用途。
- SQLite 只接收加密的账号负载；nonce 注册、导入批次、随机 ID 和数量等结构信息可见。
- v1 数据库上限 64 MiB，条目上限 10,000；常规字段上限 2,048 字符，密码和备注各 65,536 字符，主密码上限 1,024 字符。
- KDF、文件长度、数据库结构和负载大小在读取时校验。遇到错误不覆盖原库。

更改主密码重新包裹相同的数据密钥，历史备份继续使用旧主密码。它不等同于轮换全部数据密钥，也不能撤回已复制的历史备份。

## CSV 导入

支持 UTF-8（包括 BOM）和带引号、逗号、转义引号及字段内换行的 CSV。要求首行为字段名；本地映射名称、用户名、密码、网址、备注和分类。

常见浏览器及 Bitwarden 字段名可以自动识别，也可手动修改映射。预览只显示名称和数量；映射为密码或保密备注的列不能同时映射到列表字段。默认追加，可选择跳过同名且同用户名的账号；不会静默覆盖现有密码。

单次导入上限为 10 MiB、10,000 行、64 列；导入在同一事务内提交，并以批次 ID 防止同一操作重试造成重复。程序不自动删除来源 CSV，请自行管理这些明文文件。

## 备份与恢复

`.memovault` v1 包含魔数、快照长度、完整 SQLite 一致性快照及 HMAC-SHA256 认证。认证密钥通过 HKDF 从库数据密钥派生，并使用独立的用途和库 ID 作为上下文。账号负载与主密码信封本身仍有各自的认证标签。

每天首次成功修改后生成日备份，并保留每周首份周备份；每个密码库分别保留最近 7 份日备份和 4 份周备份。文件名包含密码库 ID，以免恢复其他密码库后被原库的同日/同周备份阻止。旧版日期命名的备份和其他库的备份保留原样。

修改主密码时会强制刷新当天备份。备份失败不撤销已经成功的账号写入；页面保留失败提示，下次修改时强制重试日备份，并补齐缺少的周备份，直到自动备份流程成功后才清除提示。手动导出成功不会清除自动备份目标的失败状态。恢复成功后清除原库的最近备份显示，当前会话下一次修改会刷新恢复后密码库的日备份。

恢复先在隔离文件中解包并校验密码、认证信息、条目和数据库；通过后再原子替换当前库。替换前的数据库保存在同目录 `vault.db.before-restore-<随机ID>.db`，其中包含原有密钥信封和加密数据。该文件是保留的原库快照，不是 `.memovault` 导出包；需要人工恢复时，应先退出程序，再备份现状并将选定快照复制为 `vault.db`。

备份不依赖 Windows DPAPI，因此能在其他 Windows 用户或电脑上通过对应主密码恢复。`.memovault` 不是 KDBX 文件，不能改扩展名交给 KeePass 打开。

## 验证与范围

自动化测试覆盖密码和 Unicode 往返、落盘明文检查、错误密码、数据交换/篡改、KDF 参数、数据库结构、版本冲突、回收站、导入事务与幂等、备份认证和恢复、修改主密码、会话撤销和密码生成。

隔离 Windows 验收使用生产 DI 组合、实际主窗口与 WPF 控件；不启动整个生产应用生命周期或 AI 后台服务。原生剪贴板到期检查使用加速单调时钟，格式与序号操作调用真实 Windows API。测试源码在 `tests/MemoDesk.Vault.UiProbe/`。

本功能尚未经过独立安全审计。Windows 10、真实锁屏/用户切换/休眠、多屏 DPI 和 MSIX 安装后流程尚需专项验收。解锁期间的进程内存、同用户恶意程序、管理员调试、屏幕或键盘记录，以及整库旧版本回滚不在可可靠保证的保护边界内。

Windows Hello、TOTP、密码历史、KDBX 导入、浏览器扩展与云同步留待后续版本。
