# 密码库 review 问题修复记录

版本：0.10.2-preview；日期：2026-11-01。

针对同项目“Please review my uncommitted changes”报告中的 3 项问题完成修复。

## 生成密码的安全复制

生成器结果框注册 `ApplicationCommands.Copy` 的实例命令绑定，Ctrl+C、Ctrl+Insert 和右键菜单的标准 Copy 命令统一调用 `ISecureClipboard`。选区复制只复制选中文字；没有选区时禁用标准 Copy。“复制密码”按钮复制完整结果，并使用相同的安全复制方法。

复制前后检查密码库会话；复制过程中发生锁定时立即清理本次剪贴板内容。复制失败在窗口内显示提示。现有安全剪贴板的禁止历史/云同步格式和 20 秒清理策略保持生效。

## 自动备份按库区分

日备份使用 `daily-<密码库ID>-yyyyMMdd.memovault`，周备份使用 `weekly-<密码库ID>-yyyyMMdd.memovault`。恢复另一个密码库后，即使目录中有原库当天/当周备份，也会为恢复后的密码库生成独立备份；重启后仍能区分。保留规则按密码库 ID 各自保留 7 份日备份与 4 份周备份，不清理其他库及旧版日期命名的备份。

恢复成功后清除原库的最近备份显示，并安排当前会话下次修改时刷新日备份。这也覆盖恢复同一个密码库旧快照后继续保存的情况。恢复仍要求重新解锁，不修改数据库或导出包格式。

## 自动备份失败重试

失败时保留待重试状态；下次成功修改账号后重新写入日备份，并补齐缺少的周备份。只有写入和保留流程全部成功才清除失败提示。某一步成功、后续失败时继续保留提示和重试状态；手动导出成功也不会掩盖自动备份目标仍不可用的问题。

提示改为“自动备份失败，下次保存将重试；建议手动导出备份。”账号写入仍独立提交，备份失败不会撤销已经保存的内容。
