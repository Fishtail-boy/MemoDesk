# MemoDesk 0.10.4 Preview · 密码库体验改进

本次发行集中改善密码库快捷检索和新增账号流程。

## 更新内容

- 快捷唤起窗口采用紧凑搜索列表，显示用户名、分类、结果数量及无结果提示。方向键选择账号，Enter 复制密码，Ctrl+Enter 复制用户名。
- 锁定状态只展示主密码输入，解锁中显示操作反馈；搜索界面不再残留主密码标签。
- 新增账号优先展示常用字段，标签和保密备注可展开；展开时窗口随内容调整。支持自动聚焦名称、Ctrl+Enter 保存、名称缺失提示和保存中反馈。
- 分类使用下拉框，可选择已有分类，也可输入新分类；新分类随账号保存，下次可直接选择。
- 密码输入框统一样式，保留自动锁定、清空输入和安全剪贴板行为。

## 带数据更新

下载附件 `MemoDesk-0.10.4-preview-win-x64.zip`，完整解压后运行 `MemoDesk.App.exe`。推荐 Windows 11 x64，包含所需运行时。

**从托盘退出旧版 → 备份整个 `%LOCALAPPDATA%\MemoDesk` → 新版解压到新文件夹 → 启动新版。** 使用相同 Windows 用户会自动读取原来的备忘、设置与密码库；继续使用原主密码，无需导入或重建。桌面及开机启动快捷方式需改指向新 exe。

0.10.4 未修改数据库结构、密码库加密方式或备份格式。回退到 0.10.3 时先退出新版，再运行旧版即可。详细步骤及整目录恢复方法见随包 `UPDATE.zh-CN.md`，或仓库中的 [更新说明](../../packaging/UPDATE.md)。

## 验证与范围

隔离发行分支 Release 编译通过，0 警告、0 错误；261 项单元/数据库集成测试和 52 项实际 WPF 窗口检查全部通过。

另使用 0.10.3 发行包生成合成备忘、设置和密码库，验证 0.10.4 读取后可再由 0.10.3 打开：结构版本、备忘、设置、分类、密码及保密备注均保留，原主密码继续有效。全部使用隔离目录、合成账号和替身剪贴板；未打开、修改或上传用户正式数据。

本版本继续标记为 Pre-release，提供 ZIP 解压运行包。Windows 10、真实锁屏/休眠、多屏 DPI 和 MSIX 安装等范围沿用上一版本限制。

附件包含 `BUILD-INFO.json` 和 `SHA256SUMS.txt`，用于核对构建来源与下载文件。密码库使用与备份说明见 [密码库文档](../password-vault/README.md)。
