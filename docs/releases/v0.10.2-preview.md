# MemoDesk 0.10.2 Preview · 本地密码库测试版

本次测试发行版增加独立的本地密码库，并包含主密码提示与 3 项代码 review 问题修复。GitHub Release 标记为 Pre-release。

## 下载与运行

从本页附件下载 `MemoDesk-0.10.2-preview-win-x64.zip`，完整解压后运行文件夹中的 `MemoDesk.App.exe`。推荐 Windows 11 x64；压缩包包含 .NET 和 Windows App Runtime，无需另行安装这些运行时。

升级前先在系统托盘菜单中退出旧版，再启动新版。现有备忘数据、密码库和 `.memovault` 加密备份格式兼容。关闭主窗口仅隐藏到托盘，退出请使用托盘菜单。

`SHA256SUMS.txt` 提供压缩包与 `BUILD-INFO.json` 的 SHA-256 校验值；后者记录构建来源、测试数量及程序集哈希。

## 新功能

- 本地独立密码库：主密码解锁，支持账号、密码、保密备注、分类、标签、收藏及回收站；密码信息不进入备忘、工作记录或 AI。
- 使用随机数据密钥和 AES-256-GCM 加密；主密码采用 PBKDF2-HMAC-SHA256 派生密钥进行包裹，账号元信息和秘密分开加密。
- 密码生成器与默认 `Ctrl+Alt+P` 快捷检索；支持复制用户名或密码。
- 默认闲置 5 分钟锁定，可设置 1/5/15 分钟；隐藏、最小化、系统会话切换及休眠事件触发锁定。
- 安全剪贴板：设置禁止系统历史/云同步标记，20 秒后清除本程序复制的内容，并避免清除用户后来复制的其他内容。
- CSV 字段映射、预览及事务导入；支持 `.memovault` 加密备份、恢复，以及按密码库分别保留日/周备份。

## 修复

- 主密码格式不符合要求时，在输入框附近显示具体原因和字符数量；保留输入供修改。要求 12–1024 个字符，支持中文与空格，不强制字符组合。
- 生成器的 Ctrl+C、右键复制和复制按钮统一使用安全剪贴板，复制中发生锁定时清理内容。
- 自动备份文件名与保留规则加入密码库 ID，恢复其他密码库后不会被原库当天或当周的备份阻止。
- 自动备份失败后持续提示，并在下次保存时重试；整个自动备份流程成功后才清除提示，手动导出不会掩盖自动备份目标失败。

## 验证与范围

在 Windows 11 本机完成 257 项单元/数据库集成测试与 38 项实际 WPF 窗口检查。窗口检查使用隔离目录、合成账号与替身剪贴板，不启动 AI 后台服务。原生剪贴板格式、所有权与到期清理沿用 0.10.0 首版验收记录。

这是预览功能，尚未经过独立安全审计。Windows 10、真实锁屏/用户切换/休眠、多屏 DPI 和 MSIX 安装流程仍需专项验收。本次提供解压运行包，不提供签名安装程序。

主密码无法找回；历史备份继续使用导出时的主密码。Windows Hello、TOTP、浏览器扩展、KDBX 导入与云同步暂不包含在本版本。
