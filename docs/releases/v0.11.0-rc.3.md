# 备忘 0.11.0 RC3

## 数字资产

- 在工作台可以登记服务器、域名、账号会员等资产。可填写名称、类型、简介、管理链接，以及可选的到期日期和具体时刻。
- 列表按到期先后排列，标出 30 天内到期和已过期的资产。支持搜索、按状态筛选、编辑和删除。
- 在灵动岛展开备忘页，向左滑即可打开「数字资产」模块。岛内直接显示到期时间、简介和链接，也可使用左右箭头切换模块。点「管理资产」可新增或编辑。
- 资产保存在现有本地备忘数据库中。新版启动时会通过现有备份与迁移流程添加资产记录表。

## 安装与升级

从系统托盘退出旧版，再运行 `MemoDesk-0.11.0-rc.3-win-x64-setup.exe`。安装包包含灵动岛和 .NET 运行时。此候选版尚未签名，可用同页的 `SHA256SUMS-rc3.txt` 校验下载文件。

## 验证

- 307 项 .NET 单元与集成测试，包含旧版数据库升级后保留备忘、资产读写和到期状态判断。
- 原生灵动岛测试验证拖动、触控板横向事件和箭头切换，并检查已有滚轮导航和页面排序。
- 使用隔离数据验证了 Windows 工作台的资产编辑和筛选，以及 WPF 桌面岛的资产模块。
