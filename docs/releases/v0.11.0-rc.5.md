# 备忘 0.11.0 RC5

- 在主工作台查看数字资产时，可以打开灵动岛设置，返回后仍停留在原页面。后台刷新备忘时会保留正在输入的时区和 API Key。
- 关闭或最小化灵动岛设置时，其他窗口中已解锁的密码库会保持可用。关闭或最小化灵动岛中的密码库时会自动锁定。
- 从快捷录入或托盘打开密码库，会直接进入灵动岛的密码库模块。原生岛意外退出时会自动启用备用岛，可以继续查看数字资产和录入备忘。

**升级方式**

先从系统托盘退出旧版，再运行 `MemoDesk-0.11.0-rc.5-win-x64-setup.exe`。Windows x64 安装包内含原生灵动岛和 .NET 运行时。安装包尚未签名，可使用同页的 `SHA256SUMS-rc5.txt` 校验下载文件。
