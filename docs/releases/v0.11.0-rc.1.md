# MemoDesk 0.11.0 RC1 · 日常使用候选版

本轮聚焦 Windows 本地单用户使用的可靠性。提供自包含 Windows x64 解压包，正式账号数据和密码库没有用于验收，也未上传发行包。

## 改进

- 修复本地相对提醒识别的正则超时导致整条捕获失败的问题。简单规则改用非回溯匹配，超时安全回退为原文备忘。
- AI 请求的 40 秒期限覆盖响应头与正文，响应限制 1 MiB。服务错误正文不进入界面、记录或日志；取消应用保留取消语义。远程地址要求 HTTPS，本机回环服务可用 HTTP，自动重定向关闭。
- 备忘库使用 SQLite 在线快照，包含已提交的 WAL 数据。启动、正常退出和运行期间每小时刷新当日备份，保留最近 14 个日期；数据库升级前另存快照，保留最近 5 份。
- 设置中新增备忘备份导出与自动备份目录入口。普通备忘备份未加密、不包含独立密码库；恢复方法随包提供。
- 所有设置预校验后在同一数据库事务保存。错误地址或时区不会部分生效，失败时保留 API Key 输入。
- 旧程序拒绝写入更高结构版本的数据库，避免回退版本后静默损坏数据。
- 单实例按当前 Windows 用户和会话隔离，管道只允许当前用户连接。限制命令长度和读取时间，错误回调不会停止后续监听；发现旧版常驻时提示先退出。
- UI 未处理异常会提示操作失败并尝试锁定密码库，避免界面静默忽略错误。
- 新增一键发布脚本和 Windows CI，测试失败停止打包。包内记录源码提交、未提交状态和文件哈希，包外提供 SHA-256 校验。

## 审查问题修复（2026-11-03）

- 升级快照按文件名中的时间戳保留，版本号不参与时间排序；本次升级刚生成的快照优先保留，防止同秒创建或系统时钟回退时丢失本次回退点。
- 手动导出和升级快照不再清除自动备份失败状态；只有当日自动备份及保留清理全部成功，故障提示才会解除。
- 新版同时原子占用新旧互斥标记，并监听经过当前用户校验的旧版命名管道。两个启动顺序及并发启动都只允许一个主实例，旧版唤起和通知动作可转发给新版。两个标记在后台服务与退出备份完成后释放。

## 交付与使用范围

文件：`artifacts/release/MemoDesk-0.11.0-rc.1-win-x64.zip`。完整解压后运行内层文件夹中的 `MemoDesk.App.exe`；更新前从旧版托盘菜单退出。

本候选版适合已验证的 Windows 11 x64 环境中个人日常使用。未签名；公开发行前需要发行者代码签名。Windows 10、多屏 DPI、真实锁屏/休眠、MSIX 安装与通知冷启动仍沿用已有专项实测限制，不能视为本轮已经验证。

提醒仍需要应用常驻；主动退出会撤销计划，退出期间到期的提醒在下次启动补发。密码库仍未经过独立安全审计，功能和保护边界见 [密码库说明](../password-vault/README.md)。本轮未调用真实 AI、未修改用户正式数据、未推送 GitHub 或安装证书。

恢复步骤见 [解压包使用说明](../../packaging/PORTABLE-README.md)。复现完整发布检查：

```powershell
./packaging/build-portable.ps1 -RunUiChecks
```

实现依据：[SQLite 在线备份](https://learn.microsoft.com/en-us/dotnet/standard/data/sqlite/backup)、[HttpCompletionOption 超时范围](https://learn.microsoft.com/en-us/dotnet/api/system.net.http.httpcompletionoption?view=net-10.0)。
