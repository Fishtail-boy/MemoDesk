# MemoDesk · 解压运行版

推荐 Windows 11 x64。完整解压后运行 `MemoDesk.App.exe`，文件夹中的依赖必须一起保留。无需另装 .NET。

更新前请从旧程序的托盘菜单选择“退出”，再启动新版。窗口右上角的关闭按钮仅隐藏到托盘。
本候选包未作代码签名；不需要导入开发证书。公开发行前应使用发行者的代码签名证书签署。

## 使用

- `Ctrl+Alt+Space` 快捷记录；没有 API Key 也能保存备忘，`3秒后提醒我喝水` 等明确相对提醒本地生效。
- 设置中配置 AI 后，完整备忘原文会发送到所配置服务。远程地址必须使用 HTTPS；本机兼容服务可用 HTTP。
- 提醒需要应用运行。退出期间到期的提醒会在下次启动补发，Windows 勿扰也会影响通知显示。
- 密码库使用独立主密码，密码数据不发送 AI。请定期导出加密备份；主密码无法找回。

## 备忘备份

数据在 `%LOCALAPPDATA%\MemoDesk`。普通备忘在启动、正常退出时和运行期间每小时自动备份，按日期保留最近 14 份；升级结构前另外保存快照。自动备份保存在 `backups` 子目录，同一磁盘损坏时无法保护数据。

设置页可导出 `.memobak` 文件，请定期另存至其他磁盘。它包含备忘原文、工作记录、提醒、设置及 Windows 用户加密后的 API Key，不含独立密码库。**普通备忘备份未加密，请妥善保管。** API Key 换 Windows 用户或电脑后可能需重新填写。

## 恢复备忘（关闭程序后操作）

1. 从托盘选择“退出”，在任务管理器确认没有 `MemoDesk.App.exe`。
2. 打开 `%LOCALAPPDATA%\MemoDesk`。将 `memo.db`、`memo.db-wal`、`memo.db-shm`（如存在）一起移到一个新的保留文件夹，作为回退副本。不要保留旧 WAL/SHM 在目标位置。
3. 将选择的 `.memobak` 复制到数据目录，改名为 `memo.db`，再启动应用。恢复会回到备份时点，后来的更改不在备份中；旧提醒可能补发。
4. 如需回退，先退出程序并移走本次恢复产生的三个数据库文件，再把第 2 步的原文件全部放回。

密码库使用独立的 `.memovault` 加密备份，请在密码库页面恢复。不要将 `.memobak` 放进 `vault` 目录。
MSIX 运行时路径可能被 Windows 重定向，使用设置中的“打开自动备份目录”确认真实路径。

## 问题反馈

操作失败会在界面提示；诊断日志在数据目录的 `logs` 子目录。反馈前检查截图与日志并移除个人信息。
`BUILD-INFO.json` 包含版本、源码状态、测试数量和文件校验值，`SHA256SUMS.txt` 用于校验完整压缩包。
