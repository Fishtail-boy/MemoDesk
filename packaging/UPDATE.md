# ZIP 版更新与回退（0.10.4 Preview）

0.10.4 沿用 0.10.3 的数据目录和数据库结构。普通备忘、设置与密码库都保存在当前 Windows 用户的 `%LOCALAPPDATA%\MemoDesk`，不在程序解压目录。更新无需导入数据、重新建库或更换主密码。

## 推荐步骤

1. 保存正在编辑的内容，从旧版系统托盘菜单选择“退出”。主窗口右上角的关闭按钮只会隐藏窗口；任务管理器中应不再有 `MemoDesk.App.exe`。
2. 按 `Win+R`，输入 `%LOCALAPPDATA%`。将其中整个 `MemoDesk` 文件夹复制到其他备份位置，使用带日期的新文件夹名。保留全部文件和子目录，包括 `vault`、备份目录及可能存在的 `-wal`、`-shm` 文件。请在程序完全退出后复制，不要只复制一个运行中的 `memo.db`。
3. 将新版 ZIP **完整解压到一个新的文件夹**，例如 `MemoDesk-0.10.4-preview-win-x64`，保留旧版程序文件夹。
4. 运行新文件夹中的 `MemoDesk.App.exe`。使用相同 Windows 用户，会自动读到原来的备忘、设置和密码库。密码库使用原主密码解锁。
5. 确认已有记录可见、提醒正常、密码库可解锁后，将桌面快捷方式及原先设置的开机启动入口改指向新文件夹中的 exe。

新版程序文件夹里无需放入 `memo.db` 或 `vault.db`。不要删除 `%LOCALAPPDATA%\MemoDesk`，也不要点“创建密码库”或“从备份恢复”来完成普通更新。如果看不到原数据，先退出新版，确认是否用了相同 Windows 用户、是否已退出托盘中的旧进程，以及是否混用了 ZIP 和 MSIX 版本。

建议另从密码库导出 `.memovault` 加密备份并妥善保存主密码。整目录备份中的普通备忘和部分设置未加密，请将备份保存在可信位置。API Key 使用 Windows 用户加密，换电脑或用户后可能需要重填。

## 回退到 0.10.3 Preview

0.10.4 只调整密码库界面，未更改数据格式。正常退出新版后，可以直接运行保留的 0.10.3 程序；两版共用数据，不能同时运行。

只有在确需恢复更新前状态时才恢复第 2 步的副本：先退出全部 MemoDesk 进程，将当前数据目录**改名保留**，再把完整备份复制回 `%LOCALAPPDATA%\MemoDesk`。不要将两个数据文件夹合并覆盖。恢复会丢失备份之后的修改，旧提醒也可能重新出现。

这些步骤适用于 ZIP 版、相同 Windows 用户下的 0.10.3 → 0.10.4 更新；MSIX 容器或其他数据结构版本不在此回退说明范围内。
